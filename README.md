# CMSC203_Assignment5
CMSC203 Assignment 5 - Store Sales Data Processor. 

This project is a Java application that processes sales data for multiple store departments over several days. It uses ragged two-dimensional arrays to store sales information and calculates totals, averages, and the highest and lowest sales values.

The application reads sales data from an input text file, processes the information, and writes a summary to an output file. It also includes a JavaFX graphical user interface that allows users to select files and view the results.

# Features
- Uses ragged two-dimensional arrays (double[][])
- Calculates total and average sales.
- Calculates individual department totals.
- Calculates column totals.
- Finds the highest and lowest sales values.
- Reads sales data from a text file.
- Writes summary results to an output file.
- Provides a JavaFX graphical user interface.
- Includes JUnit tests for the utility methods.

# Java Files
1. SalesDataUtility.java - Contains static methods for calculating sales statistics.
2. SalesFileIO.java - Handles reading sales data and writing summary files.
3. SalesAppDriver.java - Console application driver.
4. SalesApp.java - JavaFX graphical user interface.
5. SalesDataUtilityTest.java - JUnit tests for the utility methods.
